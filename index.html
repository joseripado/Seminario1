Manual Técnico y de Usuario – Intranet Corporativa

Documentación editable y profesional

1. Introducción General

El objetivo principal ha sido crear una Intranet Corporativa de Gestión del Conocimiento, totalmente funcional en un entorno real, accesible mediante navegador web, segura, modular y construida con tecnologías modernas.

El proyecto integra:

  • Microsoft Azure como infraestructura cloud.
  • Ubuntu Server como sistema operativo base.
  • Docker como entorno contenerizado profesional.
  • Nginx Proxy Manager para gestionar HTTPS y dominios.
  • HumHub, que constituye el núcleo colaborativo.
  • MariaDB, base de datos transaccional.
  • WireGuard, VPN corporativa.
  • Character.AI, chatbot interno.
  • Integraciones reales con Trello, Corello y GitHub.
  • Espacios corporativos: Corporative Web, Cibersecurity, Marketing, Projects.
  • Scripts y comandos para mantenimiento y automatización.

2. Infraestructura: Azure Free Tier y Azure for Students

2.1 Fase 1 – Azure Free Tier

2.1.1 Creación de la Máquina Virtual

Desde el portal de Azure se creó una VM con:

  • Ubuntu Server 22.04
  • 1 vCPU
  • 1 GB RAM
  • 30 GB SSD
  • SSH por clave
  • NSG personalizado

2.1.2 Configuración inicial del servidor

ssh -i clave.pem adminred@IP_PUBLICA
sudo apt update && sudo apt upgrade -y
sudo apt install ca-certificates curl gnupg htop unzip -y

2.1.3 Instalación de Docker

curl -fsSL https://get.docker.com | sudo sh
sudo systemctl enable docker
sudo systemctl start docker

2.2 Fase 2 – Azure for Students

La migración se realizó para obtener más recursos, estabilidad y escalabilidad.

Comandos clave de migración

Parar contenedores:

sudo docker stop humhub humhub-db nginx-proxy wg-easy

Exportar base de datos:

sudo docker exec humhub-db mysqldump -u humhub -ppassword humhub > backup.sql

Copiar backup:

scp backup.sql adminred@NUEVA_IP:/home/adminred/

Restaurar:

sudo docker exec -i humhub-db mysql -u humhub -ppassword humhub < backup.sql

4. Puertos y Seguridad

Ver puertos activos

sudo ss -ltnp

Puertos públicos

  • 22 – SSH
  • 80 – HTTP
  • 443 – HTTPS
  • 81 – Panel Proxy Manager
  • 51820 – WireGuard
  • 51821 – Panel VPN

Puertos internos

  • 3306 – MariaDB
  • 80 – HumHub (solo interno)
